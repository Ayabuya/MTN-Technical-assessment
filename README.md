# MTN Data Engineering Technical Assessment

This repository documents a data  analysis/engineering assessment prepared for MTN. It is intended to show structured thinking around building a scalable, trusted, and governed data platform for telecom customer and transaction data.

## Purpose

The project captures responses and design notes covering key data engineering topics, including:

- Lakehouse and medallion architecture
- Pipeline design and integration patterns
- Business logic placement across data layers
- Failure recovery and operational communication
- Data quality, governance, and security controls

## What this repository contains

- Assessment answers and design documentation in the docs folder
- Supporting infrastructure and project materials in the infrastructure folder
- A consolidated Q&A document for easier GitHub viewing and presentation

## Overall function

This repository serves as a documentation portfolio for a technical interview or assessment response. It is not a production application, but a structured explanation of how a modern data platform should be designed and operated for a telecom-style environment.
