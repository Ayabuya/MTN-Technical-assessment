1. SQL & Data Transformation
You have been provided with the following three tables:
CUSTOMER
customer_id, customer_name, region, created_date
TRANSACTION
transaction_id, customer_id, store_id, transaction_timestamp, transaction_amount
LOYALTY_REWARD
reward_id, transaction_id, reward_amount, reward_status

Question A: Write a SQL query that returns for each customer and calendar month:
customer_id | month | total_transactions | total_spend | total_rewards
Include customers who made transactions but received no rewards.
Question B: Return the top 3 customers by total spend within each region for the last 90 days. 
Question C: The query runs against 2 billion transaction records and has become progressively slower. How you would diagnose and optimise this workload in Databricks?
